# 🌦️ Weather App

A simple and fast weather application that allows users to check real-time weather data for any city.

🔗 Live Demo: https://weather2-natn.vercel.app/

---

## 🚀 Features

- 🌍 Search weather by city  
- 🌡️ Temperature display  
- 💧 Humidity information  
- 💨 Wind speed  
- 👁️ Visibility  
- ⛅ Weather condition with icons  
- ⭐ Save favorite cities  
- 📅 5-day forecast  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript  
- Weather API  
- Vercel (Deployment)  

---

## ⚙️ Installation & Setup

Clone the repository:

git clone https://github.com/Ramiz-28/weather2.git

Open project folder:

cd weather2

Open index.html in your browser
